# إعداد Firebase للدردشة المحلية (مشروع مستقل)

> هذا المشروع **shop-app-1670f** خاص بالدردشة فقط، ولا علاقة له بمشروع الديون والمواد (`shop-app-6d35e`).
> كل مشروع له قاعدة بيانات وقواعد وحصة منفصلة، وفي التطبيق لكل واحد `FirebaseApp` باسم مختلف
> (`shopApp` للقديم، `chatApp` للدردشة) فلا يتداخلان. لا تغيّر شيئاً في المشروع القديم.

## 1) تفعيل تسجيل الدخول بالبريد
Firebase Console ← مشروع **Shop app** ← **Authentication** ← Get started ← تبويب **Sign-in method**
← **Email/Password** ← فعّل الخيار الأول (Email/Password) فقط (اترك Email link مطفأ) ← Save.

## 2) إنشاء قاعدة Firestore
**Firestore Database** ← Create database ← اختر **Production mode** ← اختر أقرب منطقة لك
(لا تُغيَّر لاحقاً) ← Enable.

## 3) نشر القواعد
**Firestore Database ← Rules**: امسح المحتوى، والصق محتوى الملف `firebase-chat/firestore.rules` كاملاً ← **Publish**.

(بديل بالأوامر، من داخل مجلد `firebase-chat`):
```
firebase deploy --only firestore:rules --project shop-app-1670f
```
لا حاجة لأي فهارس (Indexes) مركّبة: كل الاستعلامات تعمل بالفهارس التلقائية.

## 4) حذف الرسائل الصوتية القديمة (بدون أي إعداد)
لا حاجة لـ TTL ولا لأي خدمة: التطبيق نفسه يحذف الرسائل الصوتية الأقدم من 30 يوماً عند فتح
المحادثة (القواعد تسمح بحذف الصوت المنتهي فقط). وتظهر المنتهية للحظة بعبارة
"انتهت صلاحية الرسالة الصوتية" قبل أن تُحذف.

## 5) تطبيق أندرويد المسجّل (اختياري، افعله فقط إن ظهرت رسالة خطأ المفتاح)
ملف `google-services.json` مسجّل بالـ package `com.shopapp.semochat` بينما تطبيقك `com.shopmanager.app`.
غالباً تعمل الدردشة كما هي بدون أي خطوة هنا. لا تحتاج "حساب Google Cloud" منفصلاً أبداً:
مشروع Firebase هو نفسه مشروع Google Cloud وبنفس حسابك.

إذا ظهرت داخل التطبيق رسالة "مفتاح Firebase مقيّد أو غير صالح":
1. Firebase Console ← **Project settings ← General ← Your apps ← Add app ← Android**، Package name: `com.shopmanager.app`.
2. حمّل `google-services.json` الجديد وانسخ منه `mobilesdk_app_id` و`current_key` إلى
   `ChatFirebaseConfig` (`APP_ID` و`API_KEY`) داخل `data/chat/ChatFirebase.kt`.

## 6) اختبار سريع
1. ثبّت التطبيق على جهازين (أو جهاز + حساب ثانٍ)، وأنشئ حسابين باسمين مختلفين.
2. من حساب 1: الدردشة المحلية ← **+** ← اختر المستخدم الثاني ← أرسل نصاً ثم رسالة صوتية (ضغط مطوّل على المايك).
3. في حساب 2 تظهر المحادثة بقائمته مع عدّاد غير مقروء، وعند فتحها تتحول علامة الإرسال إلى ✓✓ عند الطرف الأول.
4. تحقق في Firestore من المجموعات: `users`، `usernames`، `chats`، و`chats/{id}/messages`.

## الحصة المجانية (Spark)
الرسالة الواحدة = كتابتان (مستند الرسالة + تحديث المحادثة)، وكل مستمع يقرأ المستند الجديد مرة واحدة.
الحدود اليومية المجانية لـ Firestore (حسب علمي، راجع صفحة Firebase Pricing للأرقام الحالية):
50 ألف قراءة و20 ألف كتابة و20 ألف حذف في اليوم، و1GiB تخزين. الدردشة بين أشخاص قليلين
(مئات الرسائل يومياً) تبقى بعيدة عن هذه الحدود. الرسائل الصوتية الأثقل (≈3KB لكل ثانية) يحذفها التطبيق بعد 30 يوماً.

## ما الذي يخزَّن وأين
| المجموعة | المحتوى |
|---|---|
| `users/{uid}` | الاسم، آخر ظهور |
| `usernames/{nameLower}` | حجز الاسم الفريد → uid |
| `chats/{uidA_uidB}` | الأعضاء، آخر رسالة، غير المقروء، وقت القراءة، مؤشر الكتابة |
| `chats/{id}/messages/{msgId}` | رسالة نصية أو صوتية (Base64 AAC) + `expireAt` للصوت (30 يوماً) |
